# Movie Box Office Analysis

## About Our Project

In this project we wanted to explore whether the the amount of money a movie makes on the first week impacts the overall performance of the movie
we used data from the top 20 movies in 2008.

## Data Source

We originally planned to use Box Office Mojo but later switched to the Box Office History API.

https://www.boxofficehistory.com/api

## Files

- `weekly_box_office.qmd` - our main file where we collected and cleaned the data.
- `weekly_box_office_2008.csv` - weekly earnings for the 20 movies.
- `movie_summary_2008.csv` - first-week and total earnings for each movie.
- `omdb.qmd` - our earlier work with the OMDb API.
- `movie_analysis.qmd` - our initial work collecting box office data from Box Office Mojo.
